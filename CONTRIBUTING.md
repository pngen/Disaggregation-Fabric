# Contributing to Disaggregation Fabric

We welcome contributions to Disaggregation Fabric. By submitting a contribution
you agree to the Apache License 2.0 terms that govern this repository.

## Terms

- Contributions are licensed under the Apache License, Version 2.0.
- No Contributor License Agreement (CLA) is required.
- No AI attribution is required; do not add "Generated by" or "AI" markers to code.
- Do not add "Co-authored-by:" or other authorship trailers unless you are the
  original author of the change. Preserve legitimate third-party attribution.

## Process

1. Fork the repository and create a feature branch.
2. Make focused, well-scoped changes that preserve the systems boundary.
3. Build with the supported toolchain (C++20, MSVC, /W4 /WX) and run the test
   suite; new invariants should be accompanied by tests.
4. Keep the README truthful: do not claim hardware or behavior that is not
   physically exercised and proven.
5. Submit a pull request describing the change and why it is needed.

## Code standards

- C++20, no warnings under /W4 /WX for MSVC.
- Use the strongly typed identities and guarded lifecycles in the public API.
- Do not collapse the resource-state distinctions (present vs reachable vs
  current vs compatible vs reservable vs composition-eligible vs committed vs
  authoritative).
- Do not broaden the boundary into scheduling, brokering, or network control.
- Keep persistence integrity-checked and protocol framing canonical.
